THIRD PARTY LICENSES
====================

本文件列出 Chuying Proxy Play（褚嬴代打）Forge 1.20.1 版分发物中涉及的**全部**
第三方内容，以及本 mod 与它们之间的许可关系。分两类：

  A. 内置组件 —— 随 jar 一起分发（三个棋类引擎及其权重、内嵌库）
  B. 前置/可选模组 —— 不随本 mod 分发，仅在运行时与它们互操作

本 mod 本体以 GNU GPL-3.0-only 发布（见同目录 LICENSE）。


================================================================================
A. 内置组件（随 jar 分发）
================================================================================

自 2.0 起，引擎不再以独立可执行文件（子进程）方式调用，而是**编译成 JNI 原生库、
在游戏进程内运行**（stdin/stdout 被重定向到内存队列），不 spawn 任何 OS 进程。

A-1) Pikafish（中国象棋引擎）
   Source:  https://github.com/official-pikafish/Pikafish
   License: GNU General Public License v3.0
   说明:    随 jar 分发的 chuying_pikafish 原生库由 Pikafish 源码 + 本 mod 的
            JNI 桥接层（native/src，同样 GPL-3.0-only）链接而成，构建期补丁见
            .github/scripts/build_native.sh（重命名 main()、屏蔽 Windows 下用进程
            命令行覆盖 argv 的行为）。
   固定版本: 为保证引擎与权重配套，构建时锁定 commit
            b562d6aeac5401879e973dc53ddb56053f07bb6a。
   权重:    随附的神经网络权重 pikafish.nnue 遵循 Pikafish 的 NNUE 许可 ——
            **仅限个人、非商业用途**；任何商业使用需向 Pikafish 团队另行获取商业授权。
            NNUE 许可全文见同目录 licenses/pikafish_NNUE_LICENSE.txt

A-2) Stockfish（国际象棋引擎）
   Source:  https://github.com/official-stockfish/Stockfish
   License: GNU General Public License v3.0
   说明:    随 jar 分发的 chuying_stockfish 原生库链接 Stockfish 源码（tag sf_17.1）。
            两份 NNUE 权重（nn-1c0000000000 / nn-37f18f62d772）以独立文件随 jar 分发，
            运行时由 Java 侧通过 UCI 的 "setoption name EvalFile / EvalFileSmall"
            指向解压后的绝对路径加载。
            （3.0 起编译时定义 NNUE_EMBEDDING_OFF，权重不再 INCBIN 编入二进制，
            这样三个平台共用同一份权重文件，单库体积从约 76 MB 降到约 1 MB。）
   权重许可: Stockfish 官方 NNUE 权重随 Stockfish 一同以 GPL-3.0 分发。

A-3) Rapfi（五子棋/连珠引擎）

================================================================================
C. GPL 合规说明（对应源码获取方式）
================================================================================

上述 A 组引擎均为 GNU GPL-3.0，本 mod 本体同样以 GPL-3.0-only 发布
（见 jar 内 LICENSE），因此链接后整体仍为 GPL-3.0，许可兼容。

GPL 要求分发二进制时提供**对应源码**。本 mod 的做法：

  - 引擎源码不打进 jar（体积原因），而是在构建时从上游仓库按**固定版本**拉取：
      * Stockfish: tag sf_17.1
      * Pikafish:  commit b562d6aeac5401879e973dc53ddb56053f07bb6a
      * Rapfi:     tag 250615
  - 每个发布版本的构建产物内附带 engines/<platform>/BUILD_INFO.txt，记录三个引擎的
    仓库地址、精确 commit/tar sha256 与权重 sha256；
  - 本 mod 自身的修改（JNI 桥接层 native/src/*.cpp 与 native/CMakeLists.txt）
    **随仓库与发布 tag 一同分发**；
  - 构建脚本 .github/scripts/build_native.sh 完整公开了源码所打的全部补丁，
    据此可复现出与本 mod 完全一致的引擎二进制。
